4. Protection des données personnelles (RGPD)

4.1. Collecte de données

Ce site ne collecte aucune donnée personnelle.

Aucun formulaire de collecte, aucun cookie de traçage, aucun outil d'analyse d'audience (Google Analytics ou autre) n'est utilisé sur ce site.

Vous pouvez naviguer sur l'ensemble des pages du site sans fournir la moindre information personnelle.

4.2. Services tiers utilisés

Pour fonctionner, ce site fait appel à quelques services tiers. Voici la liste exhaustive :

  • OpenStreetMap (carte interactive de la page Enfance) : les tuiles de carte sont chargées depuis les serveurs d'OpenStreetMap. Aucune donnée personnelle n'est transmise à ce service, seule votre adresse IP est techniquement nécessaire pour recevoir les tuiles.
    Politique de confidentialité : wiki.osmfoundation.org
  • API Adresse (data.gouv.fr) (géocodage des adresses scolaires) : service public français géré par la Direction interministérielle du numérique. Aucune donnée personnelle n'est transmise.
    Politique de confidentialité : data.gouv.fr
  • cdnjs.cloudflare.com (hébergement de la bibliothèque Font Awesome pour les icônes) : service opéré par Cloudflare. Seule votre adresse IP est techniquement nécessaire pour recevoir les icônes.
    Politique de confidentialité : cloudflare.com
  • Google Fonts (police de caractères Nunito) : la police est chargée depuis les serveurs de Google. Votre adresse IP est techniquement transmise à Google.
    Politique de confidentialité : policies.google.com
    Note : Une version hébergée localement des polices est en cours de déploiement pour supprimer cette dépendance.

4.3. Cookies

Ce site n'utilise aucun cookie, ni pour le fonctionnement, ni pour le suivi, ni pour la publicité.
